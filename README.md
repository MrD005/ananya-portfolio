# Ananya Sharma — Product Designer Portfolio

A responsive portfolio website presenting Ananya Sharma's product design experience, selected work, capabilities, and case studies.

## Live website

[mrd005.github.io/ananya-portfolio](https://mrd005.github.io/ananya-portfolio/)

## Featured work

- Enterprise product design at ZS — case study placeholder while work remains confidential
- TravClan Holidays — multi-part holiday quote-building experience
- TravClan Hotels — hotel discovery, comparison, and booking experience
- Aryabhata — internal operations workflow platform

## Built with

HTML, CSS, and vanilla JavaScript. No build step is required.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.
